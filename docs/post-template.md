# Template de Post

Usá esta base para escribir futuros posts de `adrotech` y después copiá el contenido final a `src/content/posts/<slug>.md`.

## Frontmatter

```yaml
---
title: "Titulo del post"
description: "Resumen claro en una frase. Tiene que invitar a leer sin sonar genérico."
date: 2026-04-23
tags: ["tag 1", "tag 2", "tag 3"]
category: "post"
level: "intro"
featured: false
# heroImage: "./cover.png"
---
```

## Estructura sugerida

```md
Párrafo inicial corto. Dos o tres líneas como máximo.
Tiene que abrir con tensión, verdad o pregunta real.

> Idea-fuerza o frase que merezca respirar sola.

## El contexto

Explicá qué situación te llevó a escribir esto.
Dale al lector una razón concreta para quedarse.

## Lo que aprendí

Contá el problema con honestidad.
Evitá relleno y andá al punto.

## Tres ideas que sí importan

### 1. Primera idea

Desarrollo breve con ejemplo o interpretación.

### 2. Segunda idea

Desarrollo breve con ejemplo o interpretación.

### 3. Tercera idea

Desarrollo breve con ejemplo o interpretación.

## Lo que me gustaría que recuerdes

Acá va el mensaje más humano o más importante del post.

> Frase final con peso.

## Cierre

Cerrá con una idea simple, firme y recordable.
```

## Guía de estilo

- Título: corto, claro, con una tensión real.
- Bajada: una sola frase fuerte, sin humo.
- Intro: 2 o 3 párrafos cortos.
- H2: usalos para cambiar de etapa en la lectura.
- H3: usalos para listas, aprendizajes o puntos concretos.
- Blockquote: solo para frases que valga la pena aislar.
- Cierre: terminá con una idea que deje eco.

## Checklist antes de publicar

- ¿El título dice algo concreto?
- ¿La descripción resume bien el valor del post?
- ¿La intro engancha de verdad?
- ¿Hay una sola idea principal?
- ¿Sobran frases o repeticiones?
- ¿La ortografía está cuidada?
- ¿El cierre tiene fuerza?

## Convención de slugs

- Usar minúsculas.
- Separar palabras con guiones.
- Evitar tildes y caracteres especiales.

Ejemplo:

`cuando-nadie-te-contrata-todavia.md`
