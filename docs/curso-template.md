# Template de Curso

Usá esta base para estructurar cursos o rutas de aprendizaje y después pasalos a `src/content/cursos/<slug>.md`.

## Frontmatter

```yaml
---
title: "Curso gratis: título del curso"
description: "Resultado concreto que va a conseguir la persona al completar el curso."
date: 2026-04-23
tags: ["tag 1", "tag 2", "tag 3"]
category: "curso"
level: "intro"
featured: false
# heroImage: "./cover.png"
---
```

```md

```

## Guía de estilo

- Pensá el curso como una transformación, no como una lista de temas.
- Los módulos tienen que tener progresión clara.
- Evitá títulos vagos como "Introducción" o "Más contenido" si no dicen nada.
- Priorizá claridad y resultado por sobre relleno.
- Cerrá con un proyecto final o una aplicación concreta.

## Checklist antes de publicar

- ¿El resultado del curso está claro?
- ¿La audiencia correcta está definida?
- ¿Los módulos siguen una progresión lógica?
- ¿Se entiende el proyecto final?
- ¿La descripción vende bien el valor del curso?
- ¿La ortografía está cuidada?

## Convención de slugs

- Usar minúsculas.
- Separar palabras con guiones.
- Evitar tildes y caracteres especiales.

Ejemplo:

`astro-mdx-desde-cero.md`
