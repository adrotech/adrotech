# Commit Message Template (ES)

Usar este template para estandarizar mensajes de commit.

## Formato

```text
<tipo>(<alcance>): <accion concreta orientada al resultado>

Contexto:
- <por que se hizo>

Cambios clave:
- <cambio 1>
- <cambio 2>

Validacion:
- <comando>: <PASS/FAIL>

Proyecto:
- Tag: adrotech

Refs:
- OpenSpec: <change-name o "No aplica">
- Issue: #<numero o "No aplica">
```

## Tipos sugeridos

- `feat`, `fix`, `refactor`, `docs`, `test`, `chore`
